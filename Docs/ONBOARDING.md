Requirements before using Ghidra String Sniper:

Download Ghidra and it's dependencies
Have a binary file you want to analyze
Have an API key from openrouter


Steps to fully set up the plugin:
Install the Ghidra plugin off of the repository

Go to C:\Users\...\ghidra_string_sniper_ext\data\python and create a file called TOKEN to input your token into so that the script can query the LLM to analyze relevant scripts.

Go to C:\Users\...\ghidra_string_sniper_ext and run either the LinuxBuildInstall.sh or Windowsdeploy.bat file
    If you run the windows batch file you will need to enter the file paths of several different files related to this project so that it may store information and outputs generated by the scripts.

Run Ghidra
    Make a new project and import the binary file you want to analyze
    Go to File > Configure Tool > Ghidra Core (configure) and select Ghidra String Sniper Plugin.

Then select the binary file you uploaded to Ghidra and open it's CodeBrowser.

Go to the "Window" tab at the top of the screen and open the drop down menue to find Ghidra String Sniper with the reticle icon and select the option.  

Once brought up to the new pop up window, click the green refresh arrow in the top right of the tab to begin analysis.

This may take several minutes to complete.

Once the results are returned, you can select any string returned to be redirected into a deeper analysis panel where you can see the ratings given by the LLM as well as any open source repositories that this string may have been found in.
