Introduction / Proposal

Reverse engineering proprietary binaries is often hindered by stripped symbols, making it difficult to quickly understand a program’s structure and behavior. Analysts may waste time reverse engineering common libraries or rely on guesswork, leading to inaccurate conclusions.

Even stripped binaries often contain useful strings that reveal functionality, libraries, or protocols. Tools like Sourcegraph allow large-scale searching across public repositories, enabling analysts to match these strings to real implementations and import relevant headers, symbols, and structures.

Proposed Solution

  1. Extract meaningful or unique strings from a binary
  2. Query Sourcegraph for relevant code matches
  3. Use an LLM to correlate results with assembly/decompiled output
  4. Present matches for manual or automated application

Overall Goal

Reduce redundant analysis, improve identification of known components, and provide a clearer high-level understanding of a binary early in the reverse engineering process.

Status

Ghidra String Sniper is in active development. The Python backend is functional as a proof of concept, and the Ghidra extension is in progress.
